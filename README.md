# Efficient Error Mitigation for Unitary k-Designs
This notebook repo holds minimal code needed to reproduce the data presented in our paper, [arXiv:2606.03891](https://arxiv.org/abs/2606.03891). `no_coherent_error.ipynb` holds the experiments for error mitigation with only depolarizing error for a desired register size; `xx_coherent_error.ipynb` holds the experiments for various levels of XX coherent error on each two-qubit gate; `haar_random_variance_test.ipynb` holds the experiments for a 6Q Haar-random unitary compiled onto devices with increasing error variance; and `real_device_mitigation_random_loschmidt.ipynb` performs the protocol in the setting of a Loschmidt echo targeting a real IBM device. All of the packages used alongside their versions are listed in `package_list.txt`. The version of Python used is 3.12.12.

Lastly, the device characteristics at the time of the hardware demonstrations reported in our paper are available in the `csv` file in this directory. The notebook `device_specs.ipynb` can be used to compile the statistics.
